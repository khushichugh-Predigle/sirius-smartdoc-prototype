SmartDocs — Design Prototype

A static, click-through visual prototype of two app-smartdoc screens (Document Intake list and Document Detail review). All data is fabricated and held in memory — nothing here reads or writes a real backend.

Screen A

Document Intake

Searchable, filterable table of incoming documents with status chips, an advanced filter panel, and pagination.
Screen B

Document Detail

Section rail, extracted-field form with confidence badges and evidence, patient/provider match, and a document preview.
About this prototype: the app shell (top bar + sidebar) is an approximate reconstruction — app-smartdoc's real chrome comes from a private component library not included in the source repo, so this one is modeled on your sirius_clearance_specialist_v64 reference instead of a pixel copy. NPI/drug lookups, the patient match panel, and Attach-to-Case are all wired to dummy data for click-through review only.
